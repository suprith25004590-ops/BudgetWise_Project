# BudgetWise – Smart Personal Budget Planner

BudgetWise is a Python-based personal budget management application.

## Features
- Set monthly budget.
- Add and manage expenses.
- View remaining budget.
- Category-wise expense analysis.
- Overspending alerts.
- Calculate savings.
- Generate monthly reports.

## Installation

```bash
pip install budgetwise-srini
```

## Run the Application

```bash
budgetwise
```

## Technologies Used
- Python
- User-defined Python packages
- Lists and dictionaries
- Functions
- Exception handling
